# 魅族 Pro 6 刷 Linux：研究结论

> 这是前一轮阶段性结论。用户已要求继续自主移植，目标保持进行中；最新状态以《自主移植进展.md》为准。后续已取得实测root并完成本机启动/校准分区回读，本文所述“尚无备份能力”等历史门槛不再全部适用。原生Linux尚未启动。

日期：2026-10-18。对象为已通过 USB/ADB 识别的标准 Pro 6，Flyme 8.0.5.0A、Android 7.1.1、MT6797、aarch64、Linux 3.18.41+。

## 能否像之前 L36h 一样刷 Linux？

目前不能直接照搬。此次检索没有找到经过核实、可直接用于 Pro 6 的 Ubuntu Touch / postmarketOS 成套移植；这不证明世界上不存在未公开的移植。Pro 5 的 Exynos 平台和 L36h 的 Qualcomm/ARMv7 平台均与本机不同，不能互刷。

原生 Linux 仍是可调查的移植方向，但本机尚未通过自定义启动门槛，不能承诺最终成功。现阶段不要根据通用教程直接刷 Pro 5、MX6、其他 MT6797 手机或 L36h 的 boot/recovery/LK/preloader。

## 已经得到什么

| 研究项 | 证据与结论 |
|---|---|
| 本机硬件、系统与权限 | ADB 实测型号、ABI、内核、分区标签；shell 非 root，启动属性报告锁定 |
| 匹配原厂固件 | 官方固件 fingerprint 与本机完全一致；提取的5个文件长度与 ZIP CRC32 匹配 |
| 原厂 boot | 已提取并解析头部、ramdisk、附加 DTB；内核构建信息与实机一致 |
| 原厂 recovery | 从本机可读补丁和资源文件重建；计算的 header ID 与本机预期一致；内嵌签名通过 |
| fastboot 能力 | LK 静态注册段未发现 boot / 常见 unlock 命令；这是静态结果，未动态实测 |
| 内层签名 | AOSP 公开 verity 测试密钥匹配，能逐字节重现原厂签名 |
| 外层校验 | boot/recovery/LK 的 cert2 头部与载荷 SHA256 匹配，相关 RSA-PSS 签名数学验证通过；设备信任根未确认 |
| L36h 经验 | 可复用备份、独立救援、逐项硬件及长时验收方法，不能复用镜像、分区编号或驱动 |

最关键的发现：**能重新生成 AOSP 内层签名，不代表修改后的 boot 能通过 MTK 外层校验。内核与 ramdisk 确实在外层已签名散列的覆盖范围内。**

## 推荐的原生移植路线

第一阶段应以“原厂内核 + 匹配 DTB + 最小 Linux initramfs”为目标，先获得 USB shell/网络，再逐步适配 Wi-Fi、显示、触控、电源和温控。原厂启动配置提供了 USB RNDIS 的研究线索，但尚未在独立 Linux 中验证。

Ubuntu Touch 桌面需要再解决图形与硬件适配层；主线 Linux 还需要更广泛的板级驱动工作。现阶段先下载通用发行版 rootfs，不能解决启动链问题。

如果实际用途只是跑服务，Flyme 下 chroot/proot 是另一种选择，但它保留 Android 内核，不算已经刷入原生 Linux。本研究没有用该方案替代原生目标。

## 实际动手前仍缺少的条件

1. 可用的本机 root 或其他已验证只读分区备份通道，以及 boot/recovery/GPT/本机校准分区的完整备份。
2. 经实机验证的恢复入口和写回能力。重建 recovery 文件不等于已验证救砖；原厂 recovery 的普通 ADB shell 配置未开放。
3. 已验证的外层校验处理或正式解锁路径。mtkclient 芯片配置与通用证书工具不等于本机支持。
4. 第一次最小原生启动实测，之后才能评估硬件可用程度与长期稳定性。

若继续实操，最先处理的是解锁亮屏后核查官方 Root 开启/申请条件。账号验证需由用户自行完成；root 权限管理显示应用列表不等于 Root 已开启。不要先刷修改 boot 再寻找恢复方式。

## 本研究的交付与验证范围

本次请求为“研究 Pro 6 刷 Linux，参考 L36h”。已完成实机只读调查、现有移植/源码调查、L36h 对照、原厂启动与恢复材料分析、签名验证和技术路线评估，交付结论是“尚无可直接照做的已核实路线，需要从启动链开展移植”。它不是安装成功或完整刷机教程的声明。

固件条目校验与内层签名、外层证书校验已在整理结论前重新运行，脚本均退出0。未下载并校验完整原厂 ZIP；未确认设备信任根；未对手机进行 root、解锁、重启、擦除或刷写，也未启动原生 Linux。上述未验证事项保持为后续实操门槛。
